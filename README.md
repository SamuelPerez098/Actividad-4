**Nombre del proyecto:** Portafolio Personal

**Autor:** Samuel Pérez Ramírez

**Descripción breve:**  
Portafolio web personal desarrollado como parte de mi formación en Ingeniería en Sistemas Computacionales. El sitio presenta información sobre mi perfil, educación, habilidades tecnológicas, intereses, proyectos académicos y certificaciones.

---

# Descripción del proyecto

Este proyecto consiste en un portafolio web personal creado a partir de una plantilla prediseñada y posteriormente adaptado con información, contenido y proyectos propios.

## Tecnologías utilizadas

El proyecto utiliza:

- **HTML5** para la estructura del contenido.
- **CSS3** para los estilos y personalización visual.
- **JavaScript** para la interacción de la navegación.
- **Bootstrap 5.2.3** como framework CSS.
- **Font Awesome 6.3.0** para los iconos.
- **Google Fonts** para las tipografías.
- **GitHub** para alojar y mostrar los proyectos.

### Framework CSS

El framework CSS utilizado es **Bootstrap 5.2.3**.

No se utiliza Tailwind CSS. El archivo `styles.css` contiene los estilos compilados de Bootstrap, además de los estilos propios de la plantilla Start Bootstrap Resume.

### Plantilla utilizada

La plantilla utilizada es:

**Start Bootstrap - Resume v7.0.6**

La plantilla proporciona una estructura de currículum/portafolio de una sola página con navegación lateral y desplazamiento entre secciones.

### Descarga de la plantilla

La plantilla original puede descargarse desde:

https://startbootstrap.com/theme/resume

# Proceso de creación

## Paso 1. Selección de la plantilla

Primero se seleccionó la plantilla **Start Bootstrap - Resume**, debido a que proporciona una estructura adecuada para crear un currículum y portafolio personal.

La plantilla ya incluye una navegación lateral, secciones organizadas y diseño adaptable a diferentes tamaños de pantalla.

---

## Paso 2. Identificación del framework

Se revisaron los archivos proporcionados por la plantilla para determinar qué framework CSS utilizaba.

El archivo `styles.css` indica que la plantilla utiliza:

**Bootstrap 5.2.3**

También contiene los estilos correspondientes a Start Bootstrap Resume.

No se agregó Tailwind CSS, por lo que el proyecto utiliza un solo framework CSS.

---

## Paso 3. Adaptación del HTML

El HTML original contenía información de ejemplo correspondiente a una persona ficticia.

Se reemplazó esa información por los datos del autor del proyecto.

Se modificaron principalmente:

- Nombre.
- Título del sitio.
- Descripción personal.
- Información académica.
- Experiencia.
- Habilidades.
- Intereses.
- Proyectos.
- Certificaciones.
- Enlaces de GitHub.

También se tradujeron los nombres de las secciones y elementos de navegación al español.

---

## Paso 4. Modificación de la sección de experiencia

La plantilla originalmente mostraba diferentes puestos laborales y empresas ficticias.

Estos elementos fueron eliminados porque no correspondían al perfil del autor.

En su lugar, la sección fue adaptada para mostrar experiencia obtenida mediante:

- Proyectos académicos.
- Desarrollo web.
- Programación.
- Bases de datos.
- Programación lógica.

De esta manera, el contenido representa mejor la experiencia actual del estudiante sin agregar experiencia laboral que no corresponde.

---

## Paso 5. Modificación de educación

La información educativa original de la plantilla fue reemplazada.

**Instituto Tecnológico de Oaxaca**

Se agregó el interés por el software libre, el código abierto y Linux.

## Paso 8. Creación de la sección de proyectos y certificaciones

La sección original de **Awards & Certifications** contenía premios y certificaciones ficticias.

Esta sección fue reemplazada completamente por **Proyectos y Certificaciones**.

Se agregaron tres proyectos de GitHub:

1. Proyecto Interfaz CyberITO.
2. CONVERTIDOR de Unidades de Almacenamiento.
3. APUNTES-ITO.

Cada proyecto cuenta con un enlace que redirige al repositorio correspondiente en GitHub.

También se agregaron tres certificaciones en formato PDF.

Los archivos se organizan dentro de la carpeta `certificaciones/` y cada enlace abre el documento correspondiente en una nueva pestaña.

---

## Paso 9. Revisión del JavaScript

El archivo `scripts.js` mantiene una estructura sencilla porque la plantilla ya proporciona gran parte de la funcionalidad necesaria.

El JavaScript realiza principalmente dos funciones:

### ScrollSpy

Se utiliza `Bootstrap.ScrollSpy` para identificar automáticamente la sección visible de la página y actualizar el elemento correspondiente del menú de navegación.

Esto permite que el menú lateral indique la sección que se está visualizando.

### Menú responsive

También se agrega un evento a los enlaces de navegación para cerrar automáticamente el menú cuando se selecciona una sección en dispositivos donde el menú aparece como botón desplegable.

No fue necesario agregar frameworks de JavaScript como React, Angular o Vue.
